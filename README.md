# FRAMEFORGE AI

LLM-directed, code-rendered video generator. Initial prototype with five studio modes, a Node.js web server and a Python/FFmpeg renderer.

## Quick start

Install Node.js, Python 3, FFmpeg and the Python packages in `requirements.txt`. Then run `npm start` and open `http://localhost:3000`.

This repository contains an experimental prototype, not a production-ready deployment. Do not expose it publicly without authentication and security hardening.
